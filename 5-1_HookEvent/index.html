    Plugins Structure for HADK

    Doc Constructure

    hadk-plugin-py/
├── .hadk-plugin/
├── hooks/
├── scripts/
├── skills/
└── settings.json
    • .hadk-plugin/ - plugin config
    • hooks/ - Hook config ( pls refer Hook Json Format )
    • scripts/ - Scripts ( js , python or etc. )
    • skills/ - TPD
    • settings.json - config file

    Note: Only hooks/hooks.json and scripts/* contents are functional.

    Hook Json Format

    {
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python3 ${CLAUDE_PLUGIN_ROOT}/scripts/events/session-start-event-check.py"
          }
        ],
        "matcher": "^(?!hadk_read$).*"
      }
    ],
    "UserPromptSubmit": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python3 ${CLAUDE_PLUGIN_ROOT}/scripts/events/user-prompt-submit-event-check.py"
          }
        ]
      }
    ],
    "PreToolUse": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python3 ${CLAUDE_PLUGIN_ROOT}/scripts/events/pre-tool-use-event-check.py"
          }
        ],
        "matcher": "hadk_write|hadk_read|hadk_edit"
      }
    ],
    "PostToolUse": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python3 ${CLAUDE_PLUGIN_ROOT}/scripts/events/post-tool-use-event-check.py"
          }
        ],
        "matcher": "hark_edit"
      }
    ],
    "PostToolUseFailure": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python3 ${CLAUDE_PLUGIN_ROOT}/scripts/events/post-tool-use-failure-event-check.py"
          }
        ],
        "matcher": ".*"
      }
    ],
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python3 ${CLAUDE_PLUGIN_ROOT}/scripts/events/stop-event-check.py"
          }
        ]
      }
    ],
    "SessionEnd": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python3 ${CLAUDE_PLUGIN_ROOT}/scripts/events/session-end-event-check.py"
          }
        ],
        "matcher": ".*"
      }
    ]
  }
}

- matcher: accepts regular expressions.
- Native Tools in HADK:  `hadk_read`, `hadk_write`, `hadk_edit`, `hadk_find`, `hadk_exec`

    SessionStart

    Input Struction

    {}

    Output Struction

    {
    "hookSpecificOutput": {
        "hookEventName": "SessionStart",
        "additionalContext": "Current branch: main",  
        "sessionTitle": "main",
    }
}
    • additionalContext: assembling HADK Context Session
    • initialUserMessage: the first user message of the session (only applicable in non-interactive mode -p)
    • sessionTitle: set the session title
    • watchPaths: the array of absolute paths to watch
    • reloadSkills: a boolean value, when true, re-scan the skill directory

    UserPromptSubmit

    Input Struction

    {
  "prompt": "Tell me the news from MLB today"
}

    Output Struction

    output format 1: (TPD)

    {
  "decision": "block",
  "reason": "Explanation for decision",
  "hookSpecificOutput": {
    "hookEventName": "UserPromptSubmit",
    "additionalContext": "当前时间：2026-06-18T18:17:14.072292"
  }
}

    output format 2: decision is allow

    {
  "hookSpecificOutput": {
    "hookEventName": "UserPromptSubmit",
    "additionalContext": "当前时间：2026-06-18T18:17:14.072292"
  }
}

    the value of additionalContext will be appended at the end of the prompt.

    "pattern": "**/foo.md"
  },
  "tool_use_id": "chatcmpl-tool-a57db6d1c138b9ce",
  "user_approved": false,
  "user_reason": ""
}

    example of hadk_write

    {
  "tool_name": "hadk_write",
  "tool_input": {
    "tool_input": {
      "content": "用户输入：在 foo.md 里， 写入当前事件\n当前时间：2026-06-22T10:06:20.552218\n",
      "file_path": "/[REDACTED]/foo.md"
    }
  },
  "tool_use_id": "chatcmpl-tool-85a42a9829b00c1e",
  "user_approved": false,
  "user_reason": ""
}

    Output Struction

    {
  "hookSpecificOutput": {
    "hookEventName": "PreToolUse",
    "permissionDecision": "ask",
    "permissionDecisionReason": "Access to password.md requires user confirmation"
  }
}
    • permissionDecisionReason： the reason for the action
    • permissionDecision: allow | deny | ask
    • allow: allow the tool use
    • deny: prevent the tool use
    • ask： ask the user whether to allow the tool use
    • 1：allow
    • 2：deny

    Standart of Claude Code

    {
  "decision": "block",
  "reason": "Condition not met, continue working",
  "hookSpecificOutput": {
    "additionalContext": "Non-error feedback for HADK"
  }
}
    • decision: "block" : block Claude to stop (gotta go ahead)
    • reason: when decision is "block" , tell HADK why you need to go ahead
    • hookSpecificOutput.additionalContext: 非错误反馈，对话继续但显示为 hook 反馈

    or 

    {
  "hookSpecificOutput": {
    "hookEventName": "Stop",
    "additionalContext": "Additional information for HADK"
  }
}
